About Our Project

A delivery person has a bag with limited weight capacity. The goal is to select packages that provide the maximum total value without exceeding the bag capacity.

This project solves the 0/1 Knapsack Problem using Brute Force, Greedy, Dynamic Programming and Backtracking.

Algorithm Complexity Comparison

Algorithm Time Complexity Space Complexity Optimal?
Brute Force O(n × 2ⁿ) O(n) Yes
Greedy O(n log n) O(n) Not always
Dynamic Programming O(n × W) O(n × W) Yes
Backtracking O(2ⁿ) O(n) Yes

n = Number of packages, W = Bag capacity.
